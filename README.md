Customer Support Staffing Optimisation
Overview
Built a workforce planning solution that forecasts customer-support demand, calculates staffing requirements using Erlang-C queueing theory, optimizes agent schedules using integer programming, and validates performance using discrete-event simulation.

Project Workflow
Customer Contacts → Demand Forecasting → Erlang-C Queueing Model → Staffing Requirements → Workforce Optimization → Simulation Validation → Power BI Dashboard

Features
Synthetic multi-channel support data generation
Demand forecasting by day and hour
Erlang-C staffing calculations
Workforce optimization using PuLP
SimPy simulation validation
Executive Power BI dashboards
Key Results
Generated 66K+ customer contacts
Optimized staffing schedules across Phone, Chat, and Email channels
Reduced staffing costs while maintaining SLA targets
Validated staffing plans using simulation
